# Turn activity

Completed bot turns show one quiet expandable activity row below the answer.
The row includes successful and failed tool steps and replaces the separate digest.
Server digest duration is authoritative. A turn without a digest uses the existing
transcript duration calculation. Tool calls hidden means no activity summary.

Preserve live tool activity, legacy runs, progress text, special status rows,
chat grouping, role=log, TranscriptAnnouncer, reduced motion, trace access,
and focused-message expansion. Do not change attachment or composer behavior.

Checks:
- One collapsed row per completed turn, below its answer, with one duration.
- Failed steps remain discoverable and expandable without a red resting row.
- All tool details and the trace remain reachable.
- Focus on a folded step opens its row.
- Hidden tool calls show no new row.
- Both Simple and Advanced keep chat grouping.
- Expander and trace targets are at least 44px with accessible names.
- Typecheck, lint, i18n check, and all ChatView/activity/turn-presence suites pass.
- Desktop 1440x950 and phone 390x844 collapsed and expanded captures pass.
