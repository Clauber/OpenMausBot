# Chat document cards

The chat renders scoped local file links and gallery documents as aligned cards.
Supported CSV, TSV, HTML, text and Markdown cards open a preview on their primary target.
Each previewable card has a separate save target named for its action and file.
PDF and unknown formats say "Save only" and expose no preview.
Names truncate on one line. The second line shows the type, with no size lookup.
Targets have a minimum height of 44 pixels and visible keyboard focus.
Text previews read at most 1 MiB through the existing scoped route, render escaped source,
and retain loading, empty, failure, retry, abort and focus-return behavior.
The save hook retains retries, saved status, workspace refusal, folder listing and filenames.
Video previews remain opt-in and use 16:9 tiles at most 240 pixels tall.
Images, server endpoints, PDF rendering and poster generation are outside this change.

Acceptance evidence must include primary-preview/no-download interactions,
save-only formats, no metadata requests, workspace refusals and text read limits.
Run typecheck, lint, i18n validation and affected runnable Vitest suites with Node 24.
The coordinator owns the real chat browser check and final visual review.
