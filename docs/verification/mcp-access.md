# Apps → Access: which bot may use which app

Everything below uses a disposable fixture, a local stub standing in for the
gog Gmail/Calendar gateway, and placeholder credentials. Nothing reads the
user's OpenMausBot data or a real mail account.

## Automated checks

```sh
pnpm exec vitest run server/mcp-catalog.test.ts src/lib/mcp-access.test.ts src/components/AppAccessManager.test.ts src/components/PluginsPanel.navigation.test.ts
pnpm exec vitest run server/mcp-access.e2e.test.ts
```

`mcp-access.e2e.test.ts` launches the fake-engine fixture and a stub MCP
gateway that refuses any key but its placeholder. It proves, in order:

- the catalog lists secret names and availability, never a value;
- turning an app on installs one ordinary `mcpServers` entry through the
  same parser as every stored server, resolving its key from the fixture
  home's env file, and pins bots that follow "every enabled server" to what
  they had, so the install grants no one else;
- a granted bot's next turn mounts the app (the fake CLI's dump) and
  `GET /api/bots/:id/mcp-tools` lists the stub's tools; another bot gets
  neither;
- revoking removes both on the next turn and leaves the app installed;
- a missing secret is refused (422, names only) until a one-time value is
  sent, and a paired client session cannot install or enable.

## Browser check

Headless Chromium through Playwright, against the real renderer:

```sh
OMB_PLAYWRIGHT_CORE=/path/to/node_modules/playwright-core \
OMB_CHROMIUM=/path/to/chrome \
node --experimental-strip-types scripts/verify-mcp-access.ts .agents/screenshots
```

It opens Settings → Apps, checks that no Composio banner, card or chip is
present without a key, grants gog to one bot from the matrix, lists that
bot's tools from the By bot view, revokes, and checks the tools are gone,
asserting server state and the next turn's mounted servers at each step.
It writes `01-access-matrix`, `02-gog-on`, `03-tools-with-gog`, `04-gog-off`,
`05-tools-without-gog`, `06-bot-apps`, `07-no-composio` and `08-secret-prompt`
PNGs. It does not drive the Electron shell, only the renderer in a browser.

## The catalog

`server/mcp-catalog-data.ts` is generated by `scripts/generate-mcp-catalog.ts`
from a servers registry. It holds header and variable names plus the name of
the variable that carries each secret, never a value. Keep extra entries in
`<data dir>/mcp-catalog.json` (`{"entries": [...]}`, same shape); an entry with
a literal credential in a secret-named header or variable is skipped.
