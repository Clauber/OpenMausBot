# Local voice call round three

Clauber can test St. Paul tonight without losing answers to noise or follow-up speech.

## Scope

- Only `poc/voice-call/` changes. Use the existing isolated snapshot, never live app data.
- ElevenLabs uses one `eleven_v4_turbo` constant and 0.5 credits per character.
- One TTS WebSocket per call, one context per reply. Tokens reach TTS without waiting for sentences. Abort closes only that context.
- Only ElevenLabs gets the optional single approved audio tag rule. Tags stay intact for TTS and disappear from displayed and saved speech. AllTalk strips every square-bracket tag.
- The fast response model holds full history and may propose a self-contained `think` task. It never executes tools.
- Jev independently gates each turn using the existing product backend, threshold 0.6, budget 1.5 seconds, and a clipped full-history state. Failure starts no job.
- A permitted job runs the bot's existing agent path with the task and full history. New user turns cannot cancel it. Hangup cancels it. Additional tasks queue serially.
- Results enter history and play between spoken sentences. Decisions and job timing appear in the private page log.
- A new segment cannot cancel speech until its transcript has words. Closely spaced segments merge before playback starts.
- Account voices remain selectable. Shared-library search supports previews and adding a voice, including a clear full-slot error.

## Acceptance

- Unit tests cover tags, AllTalk, the listener parser, job survival and hangup, empty transcripts, segment merging, and existing regressions.
- Text-injected Local call proves holding speech, background completion, and survival across "Hello?".
- A short tagged Turbo line returns PCM through the WebSocket and browser playback.
- Shared-library search and selection work, or the precise external failure is recorded.
- Compare first reply token to first audio for at least three short turns on both old and new paths.
- Total ElevenLabs test spend stays below 3,000 credits. Record balances before and after.
- Read back final artifacts, run the PoC verification and quality review, update README, commit, push `clauber-fork`, and verify its head.

## Exclusions

No product integration, merge, protected push, deployment, or live-service mutation. Human listening quality and iPhone Safari require manual acceptance.

## Preserved experiment constraints

Keep the existing neutralized snapshot and copied bot thread. Never send to live port 8799 or restore live integrations or resume cursors. Leave the owned dev server, PoC server, and HTTPS tunnel running, with exact PIDs and a stop command at handoff. Private logs, audio, and copied context stay under ignored `.data/`. One active call is supported. Record empty input, provider errors, failed thinking, and interruption without treating them as zero latency.

The earlier architecture matrices remain documented in `RESULTS.md`, `RESULTS-round2.md`, and `RESULTS-local.md`. Round three replaces Local's synchronous think and sentence-based ElevenLabs acceptance. It does not repeat the billable hosted matrices within the 3,000-credit test budget.
