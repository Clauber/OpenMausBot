# Voice-call prototype acceptance

This is a throwaway instrument for choosing a call architecture. The coordinator owns the recommendation.

Inputs are the selected bot's read-only live snapshot, GSD model credentials and microphone or synthesized speech. Outputs are two callable variants, per-turn JSONL, a reproducible report and a draft PR.

- Keep all executable changes under `poc/voice-call/`.
- Never write live state, send to port 8799, restart live services, change production routes, merge or deploy.
- Snapshot the configured bot, voice, SOUL, memory and recent thread. Neutralize integrations, pending work and engine resume cursors before starting the isolated server.
- Reuse the configured bot driver against the dev instance. Confirm it creates a new engine session in the copied thread.
- Give both variants the complete copied context and the same ElevenLabs voice.
- Probe every listed response/thinking/hosted model. Reach at least three distinct providers or gateways. Record failed HTTP statuses.
- Expose both variants behind one HTTPS switcher, with buffer, response model and thinking model controls.
- Exercise the actual page's WebRTC connection and both variants' real audio path.
- Run five speech scenarios across engine buffer off/on with two response models and thinking=bot, plus the hosted default.
- Keep each long conversation open for at least 180 seconds. Observe an actual interruption event. Verify memory and local-tool requests call think.
- Record timestamp sources, first text, first audio proxy, think duration, interruptions and errors. Do not count failures or missing data as zero latency.
- Inspect real outputs and publish the report, failure notes and evidence paths.
- Read the full staged diff, pass attribution checks, commit and push to Clauber/OpenMausBot. Open a draft from `feat/voice-call-poc` to `chore/voice-call-poc-base`, whose base is exactly `e5e155bdd`. Verify that the PR contains only `poc/voice-call/` files. Never push main or modify gsdtechsolutions/Legion.
- Leave the dev server, PoC server and tunnel running. Report exact PIDs, ports, snapshot path and safe stop command.

Empty prompts, missing secrets, rejected model calls, failed thinking, interruption and stale call events must produce recorded failures or bounded cancellation. The prototype permits one active call. It has no production integration or migration promise.

Evidence and remaining limitations belong in `RESULTS.md`. Source-private runtime evidence remains ignored under `.data/`.
